# Module Responsibilities

## Website Modules
- **Landing** — marketing surface (Hero, Nav, Features, Why Veytrix, Showcase, FAQ, Footer).
- **Editor** — Manual Editor Workspace (Top Nav, Left Sidebar, Preview Player, Timeline, Editing Toolbar, Properties Panel, Asset Library, Export Center, Project Settings).
- **Templates** — reusable project templates.
- **Learning** — Learning Center.
- **Support** — Support Center.
- **Company** — About / Careers / Legal / Press.
- **Settings** — user & workspace settings.
